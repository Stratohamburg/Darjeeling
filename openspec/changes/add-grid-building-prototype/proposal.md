# Proposal

## Why

项目需要一个可在浏览器中操作的 2D 建造原型，验证玩家能否直观地在方格地图上选择建筑、预览占地、确定位置并二次确认开工。先建立可靠的网格占用与可撤回的摆放流程，为后续扩展建筑内容和玩法提供基础。

## What Changes

- 建立 React + PixiJS 的网页应用，使用 TypeScript 和 Vite；React 承载右侧建筑列表和操作按钮，PixiJS 绘制正俯视地图、建筑、幽灵及施工效果。
- 提供正方形网格和四种示例建筑，覆盖 1 × 1、2 × 2、3 × 2、3 × 3 的矩形占地，以格子判断边界和重叠。
- 选择建筑后显示跟随鼠标并吸附网格的幽灵；有效与无效位置有明确的占地反馈。
- 点击有效位置后固定待确认建筑，显示 ✓ / ×；✓ 才创建施工实例并正式占地，× 恢复同种建筑的幽灵状态。
- 提供简短施工进度和完工外观，支持多个建筑独立施工，确认后继续摆放同种建筑。
- 补充核心规则测试与浏览器交互验收，覆盖多格占地、确认和取消、按钮事件隔离及重复初始化清理。

首版采用桌面鼠标操作、内存中的单局状态和简单程序化建筑图形。地图尺寸、施工时长等演示参数在设计中集中配置；地图镜头操作、建筑旋转、拆除、资源经济、存档、移动端适配及多人功能留给后续变更。

## Capabilities

### New Capabilities

- `grid-map`: 正俯视方格地图、网格坐标映射、矩形建筑占地、地图边界及格子占用判定。
- `building-placement`: 右侧建筑选择、幽灵预览、有效性反馈、固定待确认位置、确认开工、取消回退与退出摆放。
- `building-construction`: 确认后生成建筑实例、立即占用格子、独立施工进度及完工状态转换。

### Modified Capabilities

无。当前项目尚无已有能力规范。

## Impact

- 目标项目为当前仓库；经检查目前只有 OpenSpec 配置，没有应用代码、测试或前端构建配置，需要新建应用基础。
- 新增运行依赖 React、React DOM、PixiJS，开发依赖 TypeScript、Vite、对应的 React 工具链及必要的规则测试和浏览器测试工具。
- 应用划分为 React 界面、PixiJS 场景、独立的网格与建筑规则以及二者之间的交互控制层。
- 使用静态前端部署，无需后端、外部游戏服务、账户或数据库；初版刷新页面会重置本局状态。
- 本变更只新增能力，不涉及既有接口兼容或数据迁移。
