# Darjeeling 建造原型

这是一个使用 React、TypeScript、Vite 和 PixiJS 的侧视台阶建造与物流原型。玩家在实体地面上横向放置建筑，确认后施工，并为工作地点和点对点运输线主动分配人、牲畜或车辆。完整领域背景见 [项目大纲](docs/project-overview.md)。

## 环境

- Node.js 20 或更高版本
- npm 10 或更高版本

## 开发

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可使用。也可以直接运行 `npm run dev -- --host 127.0.0.1 --port 4173` 使用测试配置中的固定端口。

## 常用命令

```bash
npm run typecheck  # TypeScript 类型检查
npm test           # Vitest 规则测试
npm run test:e2e   # Playwright 浏览器验收（使用本机 Chrome）
npm run build      # 类型检查并构建生产文件
npm run preview    # 预览生产构建
```

## 操作方式

1. 从右侧「建造」选择路灯、小屋、工坊、仓库、楼梯或 2/3 格斜坡。
2. 将鼠标移动到地图查看幽灵。完整正方形亮格是实际横向占地，延伸到其他层的半透明区域是视觉高度；绿色可放置，红色表示越界、空洞、无支撑或占地冲突。
3. 点击绿色幽灵固定候选位置，再点击旁边的 **✓ 确认建造** 或 **× 取消放置**。
4. 确认后建筑立即占用其全部格子并显示施工进度；施工完成后显示成品外观。
5. 确认后会继续摆放同一种建筑。待确认时按 Esc 等同于取消，预览时按 Esc 退出摆放。
6. 楼梯和斜坡从当前格向右上方跨一层，端点和内部地面都必须有效；楼梯禁止车辆。演示地图预置了两组楼梯和两组斜坡。
7. 在「人力分配」为主体选择一个工作地点或运输线。岗位满或主体类型不兼容时拒绝分配；暂停工作只会等待。工坊和仓库完工后加入岗位和运输端点列表。
8. 在「运输线」选择两个不同节点和搬运主体，创建后到「人力分配」为线路安排同类主体。可展开实际经过路线，地图覆盖与搬运路径使用相同的道路、楼梯和斜坡。
9. 在「道路」按逻辑坐标铺设或移除底边道路，也可移除高度连接。修改后旧路线停止；点击「重算全部路线」恢复或查看阻塞原因。示例：车辆线路「茶田 → 山腰货站」在移除 `(10, 1)` 底边后阻塞，恢复石板路并重算后恢复；移除第一段斜坡后，车辆不能改用旁边楼梯。

## 演示参数

地图为 24 列、4 层，整数 `(column, level)` 从 0 开始，层级向上增加；每格为 40 × 40 个逻辑像素的正方形，列宽与固定层高相同，视口统一等比缩放。底层 `(11, 0)`、`(12, 0)` 是空洞，部分高层没有地面。普通建筑只占单层横向 1/2/3 格，视觉高度不会占用上层。建筑施工 3 秒，结构确认后立即生效。主体每半秒推进一个逻辑边；道路代价用于选路，移动速度平衡留待后续。

内置茶田、山腰货站和高地工场作为可搬运工作节点。取货、搬运、交付用于状态演示，尚无资源库存、配方、货物容量、地形编辑、多站点、存档或联网。状态保存在内存中，刷新页面重置。

## 验收

`npm run test:e2e` 验证开发服务器；构建后在 PowerShell 运行以下命令，可用同一套浏览器用例验证 `npm run preview` 的生产文件：

```powershell
$env:PLAYWRIGHT_PREVIEW = '1'
npm run test:e2e
Remove-Item Env:PLAYWRIGHT_PREVIEW
```

验收截图保存在 `artifacts/acceptance/`，覆盖施工、空洞、不同移动主体、车辆斜坡线路和阻塞状态。

检查结果、生产预览的阻塞与恢复过程见 [验收记录](docs/verification.md)。
